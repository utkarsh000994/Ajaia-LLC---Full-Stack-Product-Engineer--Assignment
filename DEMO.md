# DocFlow Demo Flow

1. Login as the owner account.
2. Create a new document.
3. Rename the document title from the top bar.
4. Add formatted content using headings and list tools.
5. Refresh the page and confirm the document persists.
6. Share the document with reviewer@example.com with viewer or editor permission.
7. Open a second browser session and sign in as the reviewer.
8. Verify the reviewer can access the document and that viewer/editor restrictions work.
9. Import a .txt or .md file and confirm the content appears in the editor.
10. Use **Import into draft** with a `.docx` file and confirm it replaces the current draft content.
11. Click **Summarize with AI** and verify the concise bullet-point summary appears in the popup without changing the document.
12. Use **Save**, refresh the page, and confirm the latest title and content persist.
13. Revoke access from the owner side and verify it no longer appears in shared access.

This flow should take approximately 3 minutes for a reviewer.
